13
Set SESSION_DOMAIN and SECURE cookies for multi-tenant subdomains
Currently SESSION_DOMAIN=null. For tenant subdomains to share the session cookie securely, set the domain and enable secure/same-site flags. Without this, cross-subdomain requests may fail.
SESSION_DRIVER=redis SESSION_LIFETIME=120 SESSION_DOMAIN=.yourcompany.com # Note the leading dot (covers all subdomains) SESSION_SECURE_COOKIE=true # Requires HTTPS SESSION_SAME_SITE=lax
MUST FIX
