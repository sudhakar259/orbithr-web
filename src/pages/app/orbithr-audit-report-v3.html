R-002 High OAuth Required Backend Recruitment — Email
Gmail/Outlook OAuth send saves to outbox but never delivers
EmailIntegrationController::send() falls into the else branch ("Gmail/Outlook OAuth send not yet implemented") and saves to outbox without delivering. The SMTP fallback works. The OAuth path requires: (1) per-integration stored access/refresh tokens, (2) token refresh logic before each send, (3) sending via Gmail API or Microsoft Graph /sendMail endpoint.
 EmailIntegrationController.php:402 Implement OAuth token refresh per integration → call Gmail API (users.messages.send) or Graph API (/me/sendMail) with stored tokens.
R-003 Medium Backend Integrations
Integration test() pings public endpoints — does not validate stored credentials
TenantIntegrationController::test() makes a Guzzle request to e.g. https://slack.com/api/api.test (public URL). This confirms internet connectivity to the provider but does NOT validate whether the tenant's stored API key or OAuth token is valid. A correctly-reachable provider with an expired token would show "verified successfully."
 TenantIntegrationController.php:136–175 For each provider, make an authenticated test call using the stored credentials (e.g., Slack auth.test with Bearer token, Google tokeninfo endpoint, etc.).
