BL-001 High Backend Leave — Accrual
Leave proration rules hardcoded; not configurable per tenant
LeaveManagementService has hardcoded proration logic: if joining day ≤ 15 → 100% accrual, else → 50% accrual. There is no admin configuration for this. Organizations with different HR policies (e.g., pro-rated by exact days worked) cannot change this without modifying source code.
 Services/LeaveManagementService.php:535,556 Incorrect leave balances for tenants with non-standard proration policies.
